# Метрики и формулы

Версия адаптера — Instagram Graph API v26.0. Определения сверены с официальной
[документацией статистики медиа](https://developers.facebook.com/docs/instagram-platform/reference/instagram-media/insights/)
и [общими правилами Insights](https://developers.facebook.com/docs/instagram-platform/insights/).
Фактическая доступность зависит от типа публикации, её возраста, разрешений и Meta.

## Сохраняемые значения

| Поле backend | Поле Meta | Единица | Применимость |
| --- | --- | --- | --- |
| `views` | `views` | число | Feed, Reels |
| `reach` | `reach` | число | Feed, Reels; оценка Meta |
| `likes` | `likes` / резервное `like_count` | число | Feed, Reels |
| `comments` | `comments` / резервное `comments_count` | число | Feed, Reels |
| `saves` | `saved` | число | Feed, Reels |
| `shares` | `shares` | число | Feed, Reels |
| `reposts` | `reposts` | число | Feed, Reels, если доступно |
| `totalInteractions` | `total_interactions` | число | Feed, Reels |
| `totalWatchTimeMs` | `ig_reels_video_view_total_time` | мс | Reels |
| `averageWatchTimeMs` | `ig_reels_avg_watch_time` | мс | Reels |
| `skipRate` | `reels_skip_rate` | % | Reels; оценка Meta |
| `facebookViews` | `facebook_views` | число | Reels с кросспостингом, если доступно |
| `crosspostedViews` | `crossposted_views` | число | Reels с кросспостингом, если доступно |
| `follows` | `follows` | число | Feed, если доступно |
| `profileVisits` | `profile_visits` | число | Feed, если доступно |

При резервном источнике `sourceField` указывает именно поле медиаобъекта.
Его не складывают с одноимённой метрикой Insights. Facebook/crossposted views
хранятся отдельно; их не прибавляют автоматически к Instagram views.

`null` означает отсутствие данных. `reason`: `not_returned` — API не вернул
значение; `not_supported` — метрика неприменима или отклонена Meta;
`permission_required` — не хватает разрешения; `invalid_value` — значение
не соответствует числовому контракту. Несколько временных значений API
не суммируются произвольно. Настоящий ноль остаётся нулём.

При проверке реального аккаунта 2026-10-02 Meta отклонила `reposts` с кодом
`100`, а `facebook_views` и `crossposted_views` — с нетранзитной ошибкой
`code=-1`, `error_subcode=2207086`. Эти ответы дают `not_supported` для
соответствующей метрики; остальные показатели сохраняются. Неизвестные ошибки,
временные сбои и rate limit не маскируются как отсутствие метрик.

## Вычисляемые показатели ролика

`interactions` — `totalInteractions` от API. Если его нет, используется сумма
`likes + comments + saves + shares`, только когда известны все четыре слагаемых.

| Показатель | Формула |
| --- | --- |
| `engagementByReach` | `interactions / reach × 100%` |
| `engagementByViews` | `interactions / views × 100%` |
| `saveRate` | `saves / reach × 100%` |
| `shareRate` | `shares / reach × 100%` |
| `viewsPerReachedAccount` | `views / reach` |
| `averageWatchRatio` | `averageWatchTimeMs / (durationSeconds × 1000) × 100%` |

Нулевой знаменатель даёт `null` с `zero_denominator`, неизвестный вход —
`null` с `missing_inputs`. Каждый расчёт возвращает формулу и входные значения.
Длительность вводится вручную и помечена источником `manual`.

Среднее время относительно длительности не показывает долю людей, досмотревших
ролик. При повторных просмотрах показатель может превышать 100%; он не обрезается.
`viewsPerReachedAccount` тоже не даёт точного числа повторных просмотров: views
и reach имеют разную методику, а reach — оценочный показатель.

## История и сравнения

Для двух снимков `A` и `B` прирост просмотров — `B.views − A.views`, скорость —
прирост / число часов между наблюдениями, процент — прирост / `A.views × 100%`.
Без двух снимков возвращается `no_baseline`. При начальном нуле процент
не определён. Если счётчик уменьшился, `netChange` сохраняет отрицательное
изменение, а показатели прироста и скорости становятся `null` с
`counter_decreased`: это может быть корректировка Meta.

История возвращается от нового снимка к старому. Расчёт относится к интервалу
возвращённой страницы; `coverage` указывает наблюдения и усечение.
Чистое изменение числа подписчиков — разница между наблюдениями, а не
отдельные количества подписок и отписок.

Benchmark использует до 100 последних публикаций того же product type и
аккаунта, исключая сам ролик. Для каждой метрики возвращаются медиана,
число доступных наблюдений и отношение к медиане. Возраст публикаций и время
сбора могут различаться; сравнение не нормализовано по возрасту.

Сводка аккаунта использует до 1000 публикаций. Даты фильтруют публикацию;
показатели — последние накопленные lifetime values, а не активность за период.
Полная сумма `value` доступна, только если значения есть у всех публикаций
и выборка не усечена. `knownSum` — сумма известных значений с явным покрытием.
Охват разных публикаций не складывается из-за пересечения аудитории.

## Границы достоверности

Instagram Insights может отставать на срок до 48 часов; статистика старше
двух лет может быть недоступна. Сервис использует органическую статистику
Instagram. Рекламные и объединённые показатели, показанные в приложении,
могут отличаться. Нельзя восстановить дневной прирост за время до первого
снимка или кривую удержания из одного среднего времени просмотра.
Backend явно возвращает время сбора и возраст данных.
