# Social Analytics: MCP и плагин Sites

Social Analytics — общий проект для всех соцсетей владельца. Первая готовая
интеграция — Instagram. Другие платформы пока не подключены; MCP не подменяет
их данные статистикой Instagram. Готовый backend и настройки Meta сохранены.

Site: https://social-analytics.scary-rustles-7p.chatgpt.site
Плагин: https://chatgpt.com/plugins/plugin_asdk_app_sites_deb527bae8d08191b6ba5ffaa6041c01
Исходники и инструкции: [chatgpt/README.md](../chatgpt/README.md).

2026-10-02 опубликована версия Sites 6, адаптер `0.3.0`, 43 MCP-инструмента
и необязательный UI resource `ui://social-analytics/control-v1.html`.
Sites подтвердил `succeeded`, `has_mcp: true`, runtime env revision 1.
Служебный источник: `cd396a071ca15422867e873c9cdbc93221b315a8`.
Публикация: `appgdep_6abfccb8f2f4819198875b5e43fc43ea`.
Приватность подтверждена после публикации: один владелец, без групп.
Код в основном репозитории: `4f3ab40`; backend `0.2.3`.

Полная дорожная карта #15 реализована вместе с #16 внутри существующего
плагина. Portable manifest содержит девять стартовых запросов, skill и
server instructions описывают знакомство, выбор цели, подходящую таблицу/
график, уместные продолжения и границы записи. Два UI инструмента композируют
существующие GET endpoints; backend не менялся для карточки. UI остаётся
необязательным, инструменты работают в обычном разговоре.

Карточка показывает аккаунты, подтверждённый полный job, отдельную последнюю
успешную страницу и историю в ограниченной выборке. Начало всей истории
не объявляется известным. Первоначальный сбор, refresh одной публикации и
opt-in расписание раздельны. Ambiguous требует клика по точному media ID;
выбор передаётся в model context и разговор. Подписи выводятся через textContent.
После неопределённого ответа проверяется прежний UUID; клиент не создаёт
повторное задание или снимок. UI не подключается напрямую к Meta/backend,
не содержит secrets и не хранит бизнес-данные отдельно от D1.

Root `pnpm check` прошёл: 45 backend и 15 MCP/UI тестов, типы, формат,
границы и обе сборки. Через MCP transport к настоящему backend проверены
22 инструмента чтения, точные/неоднозначные/пустые запросы, времена, null,
формулы, сравнение периодов, аудитория, комментарии, карточка и UI resource.
Записи контролов проверены с подменённым backend. В обычном Chrome локальная
карточка прошла отсутствие действий при открытии, светлую/тёмную тему,
ширину 320 px без переполнения, фокус и явное включение расписания на fixture.
В production расписание осталось выключенным. Через подключённый настоящий
плагин проверены поиск Stories и отчёт с четырьмя категориями navigation.

Новый переносимый архив: `chatgpt/dist/social-analytics-plugin.zip`, `0.3.0`.
Сборка Worker и экспорт исходников не содержат ключей или данных владельца.
Архив публикации содержит `.openai/hosting.json` и `dist/server/index.js`;
он построен из точного отправленного Sites Git SHA. Backend-проверки и
реальный полный обход описаны в [deployment.md](deployment.md).

## История первой публикации

2026-10-02 опубликована версия Sites 3, адаптер `0.1.2`.
Sites подтвердил `succeeded`, `has_mcp: true`, runtime env revision 1.
Служебный источник: `86f0569ebf415aeeccfb7a704e0daf3880f7130e`.
Проект: `appgprj_6abf85476cec8191928b2376b9e8626f`.
Публикация: `appgdep_6abf8ffcfba88191a386a80307b8a145`.
MCP endpoint и OAuth resource: точный адрес Site с `/mcp`.
Доступ — один владелец, без групп и внешних пользователей.

Backend key и email владельца находятся только в секретах runtime Sites.
Владелец выбран пользователем как текущий аккаунт ChatGPT в Chrome;
его email подтверждён внутри текущей сессии. Каждое чтение и изменение
проверяет доверенную identity Sites до обращения к backend.
Instagram token и Meta secret в Sites не передавались.

`pnpm check` прошёл: 22 теста backend, 8 тестов MCP, типы, форматирование,
границы модулей и обе сборки. Локальные миграции уже применены; новых нет.
Все 9 инструментов чтения прошли через MCP transport до реального backend
`0.1.7`: поиск, единственный отчёт по реальной ссылке, неоднозначный и пустой
запрос, история, сравнение, сводка, история аккаунта и определения метрик.
Проверены время сбора, возраст снимка, формулы и `null` с причинами.
Исходники и bundle проверены на отсутствие ключа backend.
Portable plugin и MCP manifests прошли официальные Agent Plugins JSON-схемы;
skill прошёл валидатор. Записи проверены с подменённым backend, без изменения
реальных названий и без запуска нового полного сбора.

В обычном Chrome страница плагина подтверждает подключённый аккаунт владельца.
В [тестовом чате](https://chatgpt.com/c/6abf8c50-2900-83eb-a3a1-44dae7c1aac8)
плагин успешно прочитал аккаунт и последние три Reels. В
[отдельном тесте](https://chatgpt.com/c/6abf8dbc-e360-83ed-a53d-d6f0a967b03f)
запрос по реальной подписи вернул точное совпадение и полный отчёт: исходные
показатели, формулы, время сбора, реальные нули и недоступные метрики.
Неоднозначный запрос «Бар» вернул кандидатов с датами и ссылками; ChatGPT
явно спросил, какую публикацию выбрать, и не подставил статистику автоматически.
Показатели отчёта по точной подписи независимо сверены с backend. Новая
синхронизация не запускалась. Вызовы из ChatGPT до опубликованного адаптера работают.
Прямые обращения к опубликованному Site из Chrome и проверочного процесса
получили `403` со страницей Cloudflare «Sorry, you have been blocked», до
приложения. Это не проверка отказа авторизации MCP. Даже временный ingress
токен Sites не изменил результат. Это ограничение прямого доступа из текущей
сети; оно не препятствовало указанным вызовам из ChatGPT.

Для использования откройте подключённый Social Analytics в чате и запросите
статистику по названию, подписи или ссылке. Если найдено несколько публикаций,
выберите кандидата. Другие соцсети потребуют отдельных интеграций backend.
Первоначальный переносимый пакет имел версию `0.1.2`.
Его manifests прошли официальные схемы; skill прошёл валидатор после обновления.
