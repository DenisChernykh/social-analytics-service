# Social Analytics — статистика Instagram и отчёты через ChatGPT

Сервис собирает публикации, комментарии и доступную статистику Instagram, сохраняет историю показателей и помогает разбирать результаты через ChatGPT. Вопросы можно задавать обычным языком: найти публикацию, посмотреть её показатели, сравнить несколько постов или разобрать выбранный период.

Назначение проекта — дать владельцу аккаунта историю и инструменты анализа, к которым можно возвращаться. Сейчас реализовано подключение Instagram через официальный API.

## Что можно делать

- **Находить публикации:** искать по сохранённому каталогу, выбирать конкретный пост или Reel и открывать подробный отчёт.
- **Следить за изменениями:** смотреть сохранённые наблюдения охвата, просмотров, реакций и других доступных показателей.
- **Сравнивать материалы:** сопоставлять публикации, в том числе в одинаковом возрасте после выхода, когда для этого есть сохранённые данные.
- **Разбирать аккаунт и периоды:** получать сводки, историю показателей аккаунта и доступные сведения об аудитории.
- **Работать с комментариями и Stories:** собирать доступные данные и использовать их в анализе.
- **Обновлять данные:** запустить сбор, продолжить прерванное задание, обновить одну публикацию или включить расписание.
- **Работать в ChatGPT:** выбирать публикации в карточке приложения и получать отчёты с датой сбора и пояснениями к метрикам.

Примеры запросов: «Найди публикации про кафе», «Сравни эти два поста», «Покажи, как менялся охват этой публикации». Если название подходит нескольким материалам, сервис предлагает выбрать нужный.

## Что я разработал

- **Интеграцию с Instagram API:** загрузку каталога, показателей аккаунта и публикаций, комментариев и доступных Stories.
- **Фоновый сборщик:** задания с сохранённым прогрессом, постраничную загрузку, расписание, учёт ограничений API и восстановление после ошибок.
- **Хранилище истории:** снимки показателей с временем получения и источником, состояние сбора и сведения о полноте данных.
- **Аналитическое API:** поиск, отчёты, сравнение публикаций, историю метрик и сводки за период.
- **Приложение для ChatGPT:** набор инструментов и карточку для выбора аккаунта, публикаций и управления сбором. Доступ ограничен владельцем.
- **Оптимизацию чтения статуса:** готовые счётчики заменили повторный пересчёт накопленной истории при каждом запросе.
- **Тесты расчётов и восстановления:** повторные операции, прерывания заданий, недоступные объекты, частичные данные и разделение аккаунтов.

## Конкретный результат оптимизации

В контрольном сравнении на рабочей базе 23 октября 2026 года расчёт статуса сборщика прочитал **5 493 строки вместо 71 140 — на 92,28% меньше**. Ответы старого и нового расчёта совпали.

Это результат для проверенного расчёта статуса. [Описание изменения и измерения](docs/collection-status-counters.md).

## Как сервис работает с данными

Каждый отчёт использует сохранённые значения и показывает, когда они получены. Недоступный показатель сохраняется как отсутствие данных; настоящий ноль остаётся нулём. Для расчётных метрик описаны формулы.

Сбор проходит небольшими шагами. После сбоя задание продолжает работу с сохранённой позиции. Ошибка отдельного объекта фиксируется отдельно, чтобы можно было вернуться к нему и проверить полноту результата.

Доступность статистики зависит от типа публикации, разрешений аккаунта и ответа Instagram. Историю изменений сервис накапливает с момента наблюдений; отчёты учитывают фактически сохранённые снимки.

## Технологии и их задачи

| Технология                   | Для чего используется                                             |
| ---------------------------- | ----------------------------------------------------------------- |
| **TypeScript, Hono и Zod**   | Серверная логика, HTTP API и проверка запросов и ответов.         |
| **OpenAPI**                  | Описание API и согласование контракта с подключением к ChatGPT.   |
| **Cloudflare Workers**       | Выполнение API и фоновых операций.                                |
| **D1 и Drizzle ORM**         | Публикации, комментарии, история метрик, задания и счётчики.      |
| **Durable Objects и Alarms** | Запуск шагов фонового сбора и восстановление расписания.          |
| **Instagram API**            | Получение доступных владельцу данных через официальный интерфейс. |
| **MCP и MCP Apps**           | Инструменты анализа и интерактивная карточка внутри ChatGPT.      |
| **Vitest**                   | Проверки логики, хранения, расчётов и работы в среде Cloudflare.  |

## Локальная разработка

Node.js 24, pnpm 11.15.1. Параметры окружения и настройка базы описаны в [руководстве по настройке](docs/deployment.md); подключение к ChatGPT — в [chatgpt/README.md](chatgpt/README.md).

```sh
pnpm install
pnpm dev
```

```sh
pnpm check
```

`check` проверяет контракт API/MCP, форматирование, типы, границы модулей, тесты и сборку. Ключи доступа задаются через локальное окружение и не добавляются в Git.
