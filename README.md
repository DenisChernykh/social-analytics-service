# Social Analytics

Сервис сбора и анализа показателей социальных сетей с получением отчётов через ChatGPT. Интеграция Instagram использует официальный API.

## Возможности

- Сбор публикаций, Stories и доступных метрик; хранение истории показателей.
- Периодная статистика, поиск публикаций и сравнение результатов.
- Фоновый сбор с контрольными точками и MCP-адаптер для аналитических запросов.

## Инженерные акценты

- Интеграция внешнего API с прикладной аналитикой и AI-интерфейсом.
- Сохраняемые задания, последовательная обработка и восстановление фонового сбора.
- Расчёт показателей с привязкой к источникам и времени получения данных.

## Стек

TypeScript, Hono, Drizzle, Vitest.
