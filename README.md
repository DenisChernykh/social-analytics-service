# Social Analytics — аналитика социальных сетей и отчёты в ChatGPT

Сервис собирает публикации и показатели, хранит историю и предоставляет инструменты для анализа контента через ChatGPT. Интеграция Instagram работает через официальный API.

## Возможности

- Сбор публикаций, Stories, комментариев и доступных показателей аккаунта и контента.
- История метрик, статистика по периодам, поиск публикаций и сравнение результатов.
- Фоновые задания с контрольными точками, повторными попытками и восстановлением обработки.
- MCP-инструменты для аналитических запросов и представления результатов в ChatGPT.
- Привязка данных к источнику и времени получения для проверки происхождения показателей.

## Что показывает проект

Разработку интеграционного сервиса от внешнего API до аналитического и AI-интерфейса. Архитектура разделяет сбор, хранение и расчёт показателей. Фоновая обработка использует Durable Object, D1 и сохраняемое состояние, а документация содержит измерения, проверки восстановления и оптимизации запросов. Это релевантно backend-разработке, data-интеграциям, автоматизации и продуктам с AI-интерфейсом.

## Разработка

Node.js 24.18.0, pnpm@11.15.1; команды выполняются из корня workspace.

```sh
pnpm install
pnpm dev
```

```sh
pnpm check
pnpm test
```

Стек: TypeScript, Hono, Drizzle, Cloudflare Workers/D1/Durable Objects, Vitest.
